# Projeto de BI e Automação – Nicopel

## Sobre o projeto
Projeto desenvolvido em Python para integração de APIs, tratamento, organização e análise de dados industriais, com foco em produção, PCP, manutenção, estoque e indicadores operacionais.

## Objetivos
- Automatizar a coleta de dados por APIs.
- Integrar informações de diferentes setores.
- Tratar e padronizar bases de dados.
- Desenvolver indicadores de desempenho.
- Gerar dashboards para acompanhamento operacional.

## Tecnologias utilizadas
- Python
- Pandas
- Requests
- Excel
- Power BI / HTML
- Plotly
- APIs REST

## Estrutura do projeto
- `consulta_producao.py`: integração e tratamento dos dados.
- `dashboard_producao.html`: visualização dos indicadores.
- `requirements.txt`: dependências Python.

## Funcionalidades
- Consulta automatizada de APIs.
- Integração de processos, setores, ordens de serviço e estoque.
- Exportação de dados para Excel.
- Geração de dashboard interativo.

## Próximas melhorias
- Integração de dados de máquinas.
- Integração de manutenção.
- Integração de funcionários.
- Evolução dos indicadores de OEE.
- Automatização da atualização dos dashboards.
